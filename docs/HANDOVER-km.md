ដូច្នេះ៖ **សូមបំពេញប្រអប់ទាំងពីរគ្រប់ពេល។** សរសេរជាភាសាអង់គ្លេស រួចសរសេរជាភាសាខ្មែរ។ វាមិនចាំបាច់បកប្រែពាក្យទល់ពាក្យទេ — សូមសរសេរឱ្យស្រួលអានក្នុងភាសានីមួយៗ។

## ការសរសេរអត្ថបទព័ត៌មាន ឬសកម្មភាព

នេះជាកិច្ចការដែលអ្នកនឹងធ្វើញឹកញាប់បំផុត។

1. នៅម៉ឺនុយខាងឆ្វេង ចុច **✍️ Activities & news**
2. ចុចរូបសញ្ញា **ខ្មៅដៃ និងក្រដាស** នៅខាងលើ ដើម្បីចាប់ផ្តើមថ្មី
3. បំពេញ៖

   | ប្រអប់ | អ្វីដែលត្រូវបំពេញ |
   |---|---|
   | **Title** | ចំណងជើង ជាភាសាទាំងពីរ |
   | **URL slug** | ចុច **Generate**។ ទុកជាអក្សរឡាតាំង — វាក្លាយជាអាសយដ្ឋានគេហទំព័រ |
   | **Date** | កាលបរិច្ឆេទថ្ងៃនេះត្រូវបានបំពេញរួច សូមប្តូរប្រសិនបើព្រឹត្តិការណ៍កើតឡើងមុននេះ |
   | **Category** | ព័ត៌មាន ព្រឹត្តិការណ៍ រឿងរ៉ាវ ឬសេចក្តីជូនដំណឹង |
   | **Cover image** | រូបភាពមេ (សូមមើលច្បាប់អំពីរូបភាពខាងក្រោម) |
   | **Summary** | មួយ ឬពីរប្រយោគ។ នេះជាអ្វីដែលបង្ហាញនៅទំព័របញ្ជី |
   | **Body** | អត្ថបទពេញលេញ |
   | **Related program** | ស្រេចចិត្ត — ភ្ជាប់អត្ថបទទៅកម្មវិធីថែទាំគ្រួសារ ការពារកុមារ ឬទប់ស្កាត់អំពើហិង្សា |
   | **Show on the homepage** | បើកសម្រាប់អត្ថបទសំខាន់។ បីអត្ថបទថ្មីបំផុតបង្ហាញនៅទំព័រដើម |

4. ចុច **Publish** (ខាងក្រោមស្តាំ)

អត្ថបទលេចឡើងនៅលើគេហទំព័រក្នុងរយៈពេល **ពីរទៅបីនាទី**។ សូមផ្ទុកទំព័រឡើងវិញ ប្រសិនបើអ្នកមិនឃើញភ្លាមៗ។

### ការកែសម្រួលអត្ថបទដែលបានផ្សាយរួច

បើកវា កែអ្វីដែលត្រូវការ រួចចុច **Publish** ម្តងទៀត។ កំណែចាស់ត្រូវបានជំនួស។

### ការលុបអត្ថបទ

បើកវា ចុច **ចំណុចបីគ្រាប់** ក្បែរ Publish រួចជ្រើសរើស **Delete**។

## ការបន្ថែមរបាយការណ៍ប្រចាំឆ្នាំ របាយការណ៍ហិរញ្ញវត្ថុ ឬគោលការណ៍

1. ចុច **📄 Reports & policies** → ឯកសារថ្មី
2. បំពេញ **Title** (ភាសាទាំងពីរ) និង **Year**
3. ជ្រើសរើស **Type**៖ របាយការណ៍ប្រចាំឆ្នាំ ហិរញ្ញវត្ថុ គោលការណ៍ ឬផ្សេងៗ
4. ផ្ទុកឡើង **PDF (English)**
5. ប្រសិនបើមានកំណែភាសាខ្មែរ សូមផ្ទុកឡើងក្នុង **PDF (Khmer)** — អ្នកទស្សនាខ្មែរនឹងទទួលបានឯកសារភាសាខ្មែរដោយស្វ័យប្រវត្តិ
6. **Publish**

គេហទំព័របង្ហាញទំហំឯកសារក្បែរការទាញយកនីមួយៗ។ អ្នកទស្សនាភាគច្រើនប្រើទិន្នន័យទូរស័ព្ទ ដូច្នេះ **សូមបង្រួមឯកសារ PDF ធំៗមុនពេលផ្ទុកឡើង។**

## ការកែសម្រួលសាររបស់នាយកប្រតិបត្តិ

1. ចុច **👤 Director's message**
2. កែប្រែ៖ រូបថត ឈ្មោះ តួនាទី ប្រយោគសំខាន់ ឬសារទាំងមូល
3. **Publish**

មានតែមួយប៉ុណ្ណោះ — អ្នកកំពុងកែសម្រួលអត្ថបទដែលមានស្រាប់ មិនមែនបង្កើតថ្មីទេ។

## ការផ្លាស់ប្តូរតួលេខនៅលើគេហទំព័រ

រាល់តួលេខនៅលើគេហទំព័រ — គ្រួសារដែលបានជួយ កុមារដែលបានទទួលសេវា ភាគរយ — អាចកែសម្រួលបាន។

1. ចុច **📊 Impact statistics**
2. បើកតួលេខដែលអ្នកចង់ផ្លាស់ប្តូរ
3. **Value** គឺជាលេខធម្មតា ប្រើសម្រាប់តម្រៀប
4. **Display value** គឺជាអ្វីដែលអ្នកទស្សនាឃើញពិតប្រាកដ។ ប្រើវាប្រសិនបើអ្នកចង់បាន `10,000+` ឬ `96%` ឬលេខខ្មែរ `៩៥%`
5. **Context line** គឺជាអត្ថបទតូចនៅខាងក្រោម ដូចជា "ចាប់តាំងពីឆ្នាំ ២០០៧"
6. **Publish**

> **សូមបំពេញ Context line ជានិច្ច។** តួលេខតែឯង អានទៅដូចជាការផ្សាយពាណិជ្ជកម្ម។ តួលេខដែលមាន "ចាប់តាំងពីឆ្នាំ ២០០៧ នៅ ១៨ ឃុំ/សង្កាត់" នៅខាងក្រោម អានទៅដូចជាភស្តុតាង — ហើយអ្នកសម្រេចចិត្តផ្តល់មូលនិធិដល់ SKO ដឹងពីភាពខុសគ្នានេះ។

## រូបថត និងការការពារកុមារ

ផ្នែកនេះសំខាន់ជាងអ្វីទាំងអស់ក្នុងមគ្គុទ្ទេសក៍នេះ។

- **កុំផ្សាយរូបថតដែលអាចសម្គាល់អត្តសញ្ញាណកុមារ** លុះត្រាតែអ្នកមានការយល់ព្រមជាលាយលក្ខណ៍អក្សរ ហើយរូបថតនោះមានសុវត្ថិភាពពិតប្រាកដ។ បើមិនប្រាកដ សូមកុំប្រើ។
- **កុំប្រើឈ្មោះពិតរបស់អ្នកទទួលផល។** នៅផ្នែក Stories សូមប្រើឈ្មោះក្លែងក្លាយ ឬអក្សរកាត់។
- រឿងរ៉ាវនីមួយៗមានប៊ូតុង **Consent confirmed**។ រឿងរ៉ាវ **នឹងមិនលេចឡើងនៅលើគេហទំព័រទេ** រហូតដល់វាត្រូវបានបើក។ សូមបើកតែនៅពេលមានការយល់ព្រមជាឯកសារពិតប្រាកដ។
- ប្រសិនបើអ្នកមានរឿងរ៉ាវល្អ ប៉ុន្តែគ្មានរូបថតដែលអាចផ្សាយដោយសុវត្ថិភាព សូមបើក **Use an illustrated avatar**។ គេហទំព័រនឹងគូររូបស្រមោលសាមញ្ញជំនួស។ នេះជាជម្រើសធម្មតា — មិនមែនជាជម្រើសទីពីរទេ។
- **រូបភាពគ្រប់សន្លឹកត្រូវការ alt text** — ប្រយោគពិពណ៌នាអ្វីដែលមានក្នុងរូបភាព សម្រាប់អ្នកដែលមើលមិនឃើញ។ Studio មិនអនុញ្ញាតឱ្យរក្សាទុកដោយគ្មានវាទេ។

សម្រាប់រូបភាពរចនាសម្ព័ន្ធអង្គការ alt text គួរពិពណ៌នា **ខ្សែរាយការណ៍ជាពាក្យ** — "ក្រុមប្រឹក្សាភិបាលត្រួតពិនិត្យនាយកប្រតិបត្តិ ដែលត្រួតពិនិត្យ…" — មិនត្រឹមតែនិយាយថា "រចនាសម្ព័ន្ធអង្គការ" ទេ។

## តើគេហទំព័រធ្វើបច្ចុប្បន្នភាពនៅពេលណា?

រាល់ពេលអ្នកចុច **Publish** គេហទំព័រកសាងឡើងវិញដោយស្វ័យប្រវត្តិ។ វាចំណាយពេល **ពីរទៅបីនាទី**។

គេហទំព័រក៏កសាងខ្លួនឯងឡើងវិញរៀងរាល់យប់ផងដែរ។ នេះជាមូលហេតុដែលការជ្រើសរើសបុគ្គលិកបាត់ដោយខ្លួនឯង នៅពេលផុតកំណត់ — អ្នកមិនចាំបាច់លុបវាទេ។

## អ្វីដែលអ្នកមិនអាចផ្លាស់ប្តូរនៅទីនេះ

ទាំងនេះត្រូវការអ្នកអភិវឌ្ឍន៍៖

- ការរចនា — ពណ៌ ពុម្ពអក្សរ ប្លង់ទំព័រ
- ទំព័រណាខ្លះដែលមាន និងរចនាសម្ព័ន្ធម៉ឺនុយ
- ប្រអប់ទម្រង់ទំនាក់ទំនង និងកន្លែងដែលសារត្រូវផ្ញើទៅ
- អ្វីៗទាក់ទងនឹងការដាក់ឱ្យដំណើរការគេហទំព័រ

អ្វីៗផ្សេងទៀត — ពាក្យទាំងអស់ រូបថត តួលេខ ឯកសារ PDF បុគ្គលិក ដៃគូ ការងារ — ជារបស់អ្នក។
