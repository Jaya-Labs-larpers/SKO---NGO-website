## Why `studio/` is a separate npm project (not a workspace)

Cloudflare Pages runs `npm install && npm run build` at the repo root. With npm workspaces it would install the Studio's dependency tree — hundreds of packages, a React runtime, and Sanity's toolchain — on every production build of a site that ships no React. Keeping `studio/` independent means the production build installs only what the website needs, builds faster, and can't accidentally bundle Studio code.

Developers run `cd studio && npm install` once. Documented in the README.

## Scripts

**Root:**
| Script | Does |
|---|---|
| `dev` | `astro dev` |
| `build` | `astro build` (the Cloudflare build command) |
| `preview` | `wrangler pages dev dist` — serves the built site *with* the Functions, the honest local preview |
| `typecheck` | `astro check && tsc --noEmit` |
| `sanity:types` | Regenerate typed GROQ results |
| `lint`, `format` | ESLint + Prettier (with `prettier-plugin-astro`, `prettier-plugin-tailwindcss`) |

**Studio:** `dev`, `build`, `deploy`, `deploy-graphql`.

## Conventions

- **TypeScript strict.** GROQ results typed via `sanity-typegen` — a renamed CMS field becomes a build error, not a blank section discovered in production.
- **Component naming:** PascalCase files, one component per file, co-located `.astro` only (no framework components unless a component genuinely needs state — currently only the form and the lightbox, both plain TS islands).
- **No component reads `import.meta.env` directly** — all config flows through `src/lib/config.ts`, which validates required vars at build time and fails loudly if one is missing.
- **All GROQ lives in `queries.ts`.** No inline query strings in pages. This is what makes a schema change auditable.
- **Every locale string goes through `t()`.** A hardcoded English string in a component is a review-blocking bug — it's the single easiest way for a bilingual site to rot.
- **Commits:** Conventional Commits. Every phase ends on its own branch merged to `main` after your gate approval, so each gate is a reviewable diff.
